## ThreadBadge

标注某个 API 必须在哪条线程上调用。四种类型，另外可以用 children 覆盖文案。

- `Window#open()` <ThreadBadge type="viewer" />
- `VirtualInventory#add()` <ThreadBadge type="any" />
- `Signal.async(...)` 的 loader <ThreadBadge type="async" />
- `Bukkit.getScheduler()` <ThreadBadge type="main" />
- 自定义文案：<ThreadBadge type="async">Paper 全局异步调度器</ThreadBadge>

在正文里它是行内元素，跟在方法名后面不会撑开行高：调用 `ReferencingInventory#refresh()` <ThreadBadge type="viewer" /> 之前，必须确认当前上下文可以访问被引用的容器，否则平台异常会原样抛出。

## BuildTabs

构建工具三选一，同一个 `groupId` 下全站同步。页面上有两个 `BuildTabs` 时，切换其中一个另一个会跟着切——下面两组可以验证这一点。

仓库：

<BuildTabs
  kotlin={`repositories {
    maven("https://repo.momirealms.net/snapshots")
}`}
  groovy={`repositories {
    maven { url 'https://repo.momirealms.net/snapshots' }
}`}
  maven={`<repositories>
  <repository>
    <id>momirealms</id>
    <url>https://repo.momirealms.net/snapshots</url>
  </repository>
</repositories>`}
/>

依赖与 relocate：

<BuildTabs
  title="build.gradle.kts"
  kotlin={`dependencies {
    implementation("net.momirealms:sparrow-ui:beta.33")
}

tasks.shadowJar {
    relocate("net.momirealms.sparrow.ui", "com.example.myplugin.libraries.sparrow.ui")
}`}
  groovy={`dependencies {
    implementation 'net.momirealms:sparrow-ui:beta.33'
}

shadowJar {
    relocate 'net.momirealms.sparrow.ui', 'com.example.myplugin.libraries.sparrow.ui'
}`}
  maven={`<dependency>
  <groupId>net.momirealms</groupId>
  <artifactId>sparrow-ui</artifactId>
  <version>beta.33</version>
</dependency>`}
/>

## SlotGrid

把结构模板画成网格。悬停任意一格会点亮同标志符的所有格子，图例右侧的数字是该标志符占用的格数。

这是实时搜索菜单的玩家背包区布局（27 格结果 + 一行导航）：

<SlotGrid
  rows={["MMMMMMMMM", "MMMMMMMMM", "MMMMMMMMM", "P###I###N"]}
  legend={{
    M: '搜索结果',
    P: '上一页',
    I: '筛选状态与页码',
    N: '下一页',
    '#': '空位',
  }}
  caption={'对应 Pane.builder("MMMMMMMMM", "MMMMMMMMM", "MMMMMMMMM", "P###I###N")'}
/>

打开 `showSlots` 会在每格右下角标出槽号，讲 `slot` 与 `x/y` 坐标换算时用得上：

<SlotGrid
  rows={["BBBBBBBBB", "B#######B", "B#######B", "BBBBBBBBB"]}
  legend={{B: '边框装饰', '#': '内容区'}}
  showSlots
/>

多字符标志符用反引号包起来，一对反引号算一格——语法与 `Structure.of(String...)` 完全一致：

<SlotGrid
  rows={["`confirm`#`cancel`", "###", "`title`##"]}
  legend={{
    confirm: '确认按钮',
    cancel: '取消按钮',
    title: '标题物品',
    '#': '空位',
  }}
/>

铁砧上栏这种极小的 Pane 也画得出来：

<SlotGrid rows={["###"]} legend={{'#': '冻结的空槽'}} showSlots />

模板写错时就地报错，不会静默画出一块错的网格：

<SlotGrid rows={["ABCDE", "ABC"]} />

<SlotGrid rows={["A`unterminated"]} />
