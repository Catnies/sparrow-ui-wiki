安装

兼容性​

项目要求
服务端Paper 或 Folia
Minecraft1.21.4 ~ 26.3，同一个构件覆盖全部版本，不需要按版本分别引入依赖
Java库以 Java 21 编译；运行时用对应 Paper 或 Folia 版本所要求的 Java 环境即可

添加依赖​

先加仓库：

  • Gradle Kotlin
  • Gradle Groovy
  • Maven
repositories {
  maven("https://repo.momirealms.net/snapshots")
}
repositories {
  maven { url = 'https://repo.momirealms.net/snapshots' }
}
<repositories>
<repository>
  <id>momirealms</id>
  <url>https://repo.momirealms.net/snapshots</url>
</repository>
</repositories>

再加依赖，并把 net.momirealms.sparrow.ui 整体 relocate 到你自己的包名下。把下面的 com.example.myplugin.libraries.sparrow.ui 换成你插件独有的目标包名：

  • Gradle Kotlin
  • Gradle Groovy
  • Maven
dependencies {
  implementation("net.momirealms:sparrow-ui:beta.33")
}

tasks.shadowJar {
  relocate("net.momirealms.sparrow.ui", "com.example.myplugin.libraries.sparrow.ui")
}
dependencies {
  implementation 'net.momirealms:sparrow-ui:beta.33'
}

shadowJar {
  relocate 'net.momirealms.sparrow.ui', 'com.example.myplugin.libraries.sparrow.ui'
}
<dependency>
<groupId>net.momirealms</groupId>
<artifactId>sparrow-ui</artifactId>
<version>beta.33</version>
</dependency>

<!-- maven-shade-plugin 的 <configuration> 里 -->
<relocations>
<relocation>
  <pattern>net.momirealms.sparrow.ui</pattern>
  <shadedPattern>com.example.myplugin.libraries.sparrow.ui</shadedPattern>
</relocation>
</relocations>
relocate 不是可选项

Sparrow UI 会把一份反射代理装进服务端类加载器，代理类的包名跟着库的运行时包名走。不 relocate 的话，任何两个携带 Sparrow UI 的插件都会在服务端类加载器里撞上同名类。

初始化​

在 onEnable 里调用一次 setUp，把你的插件实例交给库：

package com.example.myplugin;

import net.momirealms.sparrow.ui.SparrowUI;
import org.bukkit.plugin.java.JavaPlugin;

public final class MyPlugin extends JavaPlugin {

    @Override
    public void onEnable() {
        SparrowUI.getInstance().setUp(this);
    }
}

这一步会安装反射代理、创建窗口管理器与网络管理器，并把库的调度器绑到你的插件上。

插件禁用时不需要做任何事。 Sparrow UI 自己监听插件的禁用事件，会关掉窗口管理器和网络管理器，并停掉自己的调度器。

必须先 setUp，再碰 Sparrow UI 的任何类

在 setUp 完成之前，不要访问 Sparrow UI 的任何类，也不要构建 Item、Pane 或 Window。
