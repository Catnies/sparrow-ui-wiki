寻宝菜单的第五格是一块普通地板。玩家打开右下角的「宝藏探测」后，这一格要显示成绿宝石，提示宝藏就在这里；关掉探测，又变回地板。无论显示成什么，点它都应该执行原来那块地板的处理器。

把地板换成另一个物品，点击行为也跟着换了。这里想改的只有「看起来是什么」。

## 视觉映射绑定做什么

`window.setVisualizerItem(slot, mapper)` 给某个槽位设置一个显示映射，映射函数收到这个格子的实际物品，返回要给玩家看的物品。它只改变显示，不改变格子的实际内容和点击行为。

`window.visual().bind(signal)` 让 Signal 变化时重新计算视觉层。映射函数里读取 Signal 的当前值，就能按开关切换显示。

## 宝藏探测

<SignalStepDemo
  code={`
    MutableSignal<Boolean> detecting = Signal.of(false);

    Pane pane = Pane.builder("####T###D")
            .addIngredient('T', Item.builder()
                    .setItemProviderConstant(named(Material.GRAY_STAINED_GLASS_PANE, "一块地板"))
                    .addClickHandler(click -> {
                        click.player().sendMessage(Component.text("你挖开了地板"));
                    })
                    .build()
            )
            .addIngredient('D', Item.builder()
                    .setItemProviderConstant(named(Material.MAP, "开关宝藏探测"))
                    .addClickHandler(click -> detecting.update(value -> !value))
                    .build()
            )
            .build();
    Window window = Window.builder(pane).setTitle("寻宝").build(viewer);

    ItemStack mark = named(Material.EMERALD, "宝藏就在这里");
    window.setVisualizerItem(4, actual -> detecting.get() ? mark : actual);  // 槽位 4 就是 T
    window.visual().bind(detecting);
    window.open();
  `}
  title="寻宝"
  layout={['####T###D']}
  signals={[{id: 'detecting', label: 'detecting'}]}
  items={(s) => ({
    T: s.detecting ? {icon: 'emerald', name: '宝藏就在这里', nameColor: '#55ff55'} : {icon: 'gray_stained_glass_pane', name: '一块地板'},
    D: {icon: 'map', name: '开关宝藏探测'},
  })}
  steps={[
    {lines: '1-17', state: {detecting: false}, note: '菜单里有一块地板和一个探测开关。'},
    {lines: '19-22', state: {detecting: false}, refresh: ['T'], note: '槽位从 0 开始，4 对应模板里的 T。探测关闭，映射原样返回地板。'},
    {lines: '13', state: {detecting: true}, notified: ['detecting'], refresh: ['T'], note: '打开探测，视觉层重新计算，第五格显示成绿宝石。'},
    {lines: '6-8', state: {detecting: true}, output: '你挖开了地板', note: '点击绿宝石，执行的仍是地板的处理器。视觉映射不改变点击行为。'},
    {lines: '13', state: {detecting: false}, notified: ['detecting'], refresh: ['T'], note: '关闭探测，变回地板。'},
  ]}
/>

## 注意事项

:::warning[窗口上的映射只影响这名玩家]
绑定在这一扇 Window 上，所以只有它的查看者看得到变化。要让同一个 Pane 的所有查看者一起看到，就在 Pane 的视觉层设置映射并绑定来源，各层的范围见 [视觉映射](/visual/layers)。
:::

:::warning[绑定的启停]
窗口上的视觉绑定在打开时启用，关闭时暂停，`bind` 返回的 `Subscription` 可以用来提前解绑。共享 Pane 上的绑定在没有窗口查看时也可能保持活动，关掉一扇窗口不等于停止了所有共享来源。
:::

<Details summary="示例共用的物品命名方法" previewHeight={0}>

```java
private static ItemStack named(Material material, String name) {
    ItemStack stack = new ItemStack(material);
    stack.setData(DataComponentTypes.CUSTOM_NAME,
            Component.text(name).decoration(TextDecoration.ITALIC, false)
    );
    return stack;
}
```

这里使用 Paper 的 `DataComponentTypes` 和 Adventure 的 `Component`、`TextDecoration`，与 [物品渲染](/item/render) 中的写法相同。
