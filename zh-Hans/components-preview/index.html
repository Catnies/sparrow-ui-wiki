ThreadBadge​

标注某个 API 必须在哪条线程上调用。四种类型，另外可以用 children 覆盖文案。

  • Window#open() viewer 实体线程
  • VirtualInventory#add() 任意线程
  • Signal.async(...) 的 loader 异步线程
  • Bukkit.getScheduler() 服务端主线程
  • 自定义文案：Paper 全局异步调度器

在正文里它是行内元素，跟在方法名后面不会撑开行高：调用 ReferencingInventory#refresh() viewer 实体线程 之前，必须确认当前上下文可以访问被引用的容器，否则平台异常会原样抛出。

VersionBadge​

标注最低可用版本，或标注 API 还在 Beta 期可能变动。

  • 仅版本：自 beta.33 起
  • 仅变动提示：可能变动
  • 两者同时：自 beta.21 起可能变动

MinecraftSlotGrid​

将结构模板画成 Minecraft 容器，支持 rows、legend、empty、showSlots、caption、title 和 scale。

这是布局视图：每一格都显示自己的标志符，留空位的 # 也照样显示，因为读者要对着它数"哪个字符落在哪一格"。留空位不套彩色方块；传入 icons 可以把指定标志符替换成物品贴图。

几何与配色逐条对齐 minecraft.wiki 的 mcui / invslot 体系，数值取自那边的实际 CSS。悬停时只有指着的那一格发白（游戏行为），同标志符的其余格子用白色外框指认。

要展示"玩家最终看到什么"用下面的 <MinecraftWindow>，不要用这个。

MinecraftWindow​

用原版 GUI 贴图 + 原版物品图标模拟一扇打开的容器。和 <MinecraftSlotGrid> 分工明确：那个讲布局（每格显示标志符），这个讲成品（每格显示真实物品）。

悬停显示 Minecraft 样式的 Tooltip，跟随鼠标并在浏览器边缘自动避让。此组件只展示菜单外观。

ApiTable​

方法速查表。悬停某一行会在签名右侧浮出 #，点击即可得到该行的直链。

API说明线程版本
Window.builder(Pane)#用一块 Pane 建一扇普通窗口的 Builder任意线程
Window#open()#把窗口打开，返回 CompletableFuture<OpenResult>；实际打开动作由库转交给观察者所属的实体线程viewer 实体线程自 beta.33 起
Window#navigate(Window)#在同一条会话里前进到下一扇窗口viewer 实体线程可能变动
Window#backOrClose()#回退一步；已经在会话起点时关闭窗口viewer 实体线程

不填 thread 和 since 时，那两列不会渲染：

API说明
Signal.of(T)#建一个可写的状态源
Signal#map(Function)#派生出一个只读的映射视图
Signal#debounce(long)#按 tick 去抖，搜索框输入用得上
